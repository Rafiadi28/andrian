BUG #1 FIX: Perangkat Desa Prefill
───────────────────────────────────────────────────────────────────────────────
Problem:    Revisi for "perangkat desa" didn't prefill in analis form
Root Cause: Inconsistent job-type matching (case/underscore/dash variations)
Solution:   Client-side normalization + robust pattern matching
Algorithm:  strtolower(preg_replace('/[-_]/', ' ', $type))
             then strpos(normalized, 'perangkat desa')
Result:     ✅ 6/6 variants now match correctly

BUG #2 FIX: Chain Resolution
───────────────────────────────────────────────────────────────────────────────
Problem:    Auto-routing failed when multiple roles unavailable
Root Cause: Fallback targets incorrectly marked as visited
Solution:   Conditional visited marking (only for non-chain roles)
Algorithm:  if (!in_array($fallback_role, $chain)) { visited[$fallback_role]=1 }
Result:     ✅ 6/6 routing scenarios now work correctly
